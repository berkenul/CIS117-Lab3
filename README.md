# CIS 117 Lab 3

For this lab, we used Python to read `country_full.csv` and split the
countries by region. The program makes five CSV files in the `output`
folder. Each file has only the country name and region. We skipped
Antarctica because its region was blank in the original file.

## How to run it

Put `lab3.py` and `country_full.csv` in the same folder. Open a terminal
in that folder and run:

```bash
python3 lab3.py
```
